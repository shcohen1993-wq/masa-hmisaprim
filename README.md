# מסע המספרים

אפליקציית חשבון חווייתית לילדים בכיתות א׳–ג׳: שיעורים קצרים עם המחשות, סרטוני הסבר, מעבדות, תרגול מדורג עם רמזים והסברים, 15 משחקים (גם נגד השעון), מדבקות, לוח שנה ויעד שבועי עם הפתעה מההורים.

**לשחק:** https://shcohen1993-wq.github.io/masa-hmisaprim/

- בפתיחה הראשונה יוצרים שחקן לכל ילד או ילדה: שם, כיתה וצבע.
- אין הרשמה ואין שרת. השחקנים וההתקדמות נשמרים רק בדפדפן שבו משחקים.
- כדי להעביר התקדמות למכשיר אחר: אזור הורים ← גיבוי והעברה בין מכשירים.
- בטלפון אפשר להוסיף את המשחק למסך הבית ולפתוח אותו כמו אפליקציה.
